# Shared site UI contract

Follow the root [PageSpeed performance contract](../AGENTS.md#pagespeed-performance-contract) for targets, loading conventions, measurement evidence and deployment verification. Keep route-specific implementation details here.

Read README.md. Landing and docs consume this single source package. Do not copy primitives back into app folders or import app content/catalogs into shared UI. Keep app-specific composition in app components/sections/layouts.

Use Astro 7, scoped component styles/scripts, rem fixed lengths, `class:list`, native attributes and existing palette/spacing/radius/focus/motion tokens. Preserve the user's Box widths and gutters. Do not put component selectors in theme.css. Use typed shared catalogs for control messages; shared UI must remain independent of marketing/docs prose.

Fonts owns the local Latin WOFF2 faces and heading preloads for both apps. Keep versions, sizes and SIL licenses in assets/fonts; do not restore external font stylesheets. CopyButton and Tabs reserve control geometry with inert plus visibility:hidden until initialized. Inactive panels still use native hidden. Finish initial tab/fragment selection before releasing inert; enable color/background-color transitions only for pointer hover or keyboard focus, and disable both for reduced motion. Verify delayed-script dimensions, no-JavaScript readability and actual local font requests after changing these boundaries; do not override the global hidden contract.

Both Astro configs consume lib/site-build.mjs to inline stylesheets below 40 KiB while retaining larger shared CSS in cacheable files and Vite's defaults for non-CSS assets. Compare HTML transfer size, remaining blocking requests and mobile LCP before changing the threshold; do not inline every page's full CSS by default.

TextLink owns contextual documentation CTAs and their focus/hover. NavLink owns current/hover/focus and symmetric padding; indentation is a separate margin. Surface owns card appearance. Disclosure owns native summary layout. CodeFrame/CopyButton and Theme/ThemeToggle each have one implementation. DrawerStyles owns native scoped CSS normalization, close styling and reduced motion; never implement dependency gestures or focus traps here.

Shared files have their own Astro type tooling. Both app checks and format commands include shared source. Use the root Prettier configuration. A shared change requires both sites' build and browser checks, including both themes, responsive/enlarged text, repeated instances, keyboard and lifecycle cleanup. Keep setup, CI, catalogs and these maintenance notes synchronized.

Share locale resolution through i18n/createI18n.ts and safe metadata serialization through lib/serialize.ts; neither app imports sibling implementation files. During cleanup, prove references are absent before deleting. Check Astro/MDX imports, generated hooks, translated data, assets and tooling entrypoints. Preserve migration/source inventory, legal attribution, public fragments/redirects and no-JavaScript paths. Remove superseded CSS rather than adding more overrides; preserve existing computed appearance and Box dimensions.

Landing, Examples and Docs are one website. Before creating a variant, compare it to existing Home UI and reuse the implementation. Keep visual regression checks against real shared consumers; duplicated tokens or a similar screenshot are not proof of reuse. Root AGENTS.md records the cross-project decisions and previous mistakes to avoid.

CodeFrame owns Astro Code/Shiki rendering for text/language input and shared/lib/code-theme.mjs owns the single syntax configuration. Native Markdown/MDX highlighting consumes that same theme; Article only frames the result. Remove manual syntax-token arrays and separate theme objects. Preserve text exactly: Astro trims one final newline, so CodeFrame restores it through its build-time transformer. Verify actual colors, copied source, no-JavaScript output and both themes, not merely the presence of a toolbar or token spans.

CopyButton resolves code from its nearest data-copy-source frame at click time; its optional text prop is an explicit override for commands. Do not serialize complete highlighted snippets a second time into data-copy-text, or cache a separate clipboard string in Article. Preserve final newlines, literal characters, independent feedback and failure selection, and execute copied gallery files after changes.

RangeControl owns the existing demo range presentation, shared by speed and position controls. It supplies native input/focus styling and a label/slot; the owning application or package supplies behavior.

Use the shared integration labels Package / ESM and HTML / CDN. CDN is delivery, Global describes window.Ticker from the standalone script, and /browser is the optional imported registry; do not present them as competing loading modes. Direct ticker() is the introductory API in either setup; registry/page-manager ownership is a separate decision. Preserve old technical IDs and heading fragments even when visible labels improve. The public skill follows this distinction and the package runtime contract, while repository memory keeps site-specific architecture and visual conventions.

Mixed-language runnable examples use shared CodeFiles (Tabs + TabPanel + CodeFrame), with HTML, CSS and JavaScript files and an optional Complete file tab. Keep single-language API snippets focused. File copies must reference actual sibling filenames and retain package CSS/import/script ordering; the gallery's complete and separate variants share their generator. Test exact copying, nested tab keyboard behavior, no-JavaScript labels, both themes, overflow and execution of both variants. Do not create a second highlighter, clipboard handler or per-page tab controller.

Titles share Heading and PageTitle rather than page-local font rules. Heading owns the closing title’s width, centered margins and top spacing; keep these together in its closing context because unlayered heading resets override Tailwind margin utilities. Browser checks must assert centered geometry as well as typography and overflow. Heading separates semantic level from the controlled display/section scale; PageTitle composes the eyebrow, title and description. Keep the approved Home Inter/Instrument Serif pairing, weight, tracking and spacing tokens. Editorial accent text is an explicit trailing part of the translated title (titleAccent in docs frontmatter); never infer the last word or split API identifiers. Keep the full title unchanged in metadata/search and verify compiled whitespace, both themes, responsive sizes and enlarged text. API identifiers and single-word headings can remain entirely in the primary font.

Interactive site code uses arrow functions, with named functions only when useful; no classes or `this`. Components register small setup functions with `shared/lib/mount-elements.ts`, keep state in closures and return cleanup. Existing ticker-* tags are scoped DOM roots, not registered custom elements. Call package controllers directly; keep recipe content editing in ExamplePreview and controller setup in TickerDemo. Generate copied files in landing/src/lib/recipes with separate markup, styles, behavior and file assembly. Preserve controllers on persisted pagehide so browser back/forward restoration keeps working; clean up only on a real departure.

The shared ticker control catalog includes explicit hover/focus pause explanations. Consumers use these alongside manual Pause/Play labels so a temporary automatic pause is visible without overwriting requested playback or manual pause intent.
