02 / Choose your entrypoint

Built for every runtime.

Import the API your stack already uses. No polyfill, no configuration step, no global state you did not ask for.

Main

@samline/ticker

Full API plus defaults, the browser singleton, and the registry.

Vanilla

@samline/ticker/vanilla

Element-scoped controller plus the declarative page manager. Auto-discovers tickers as the DOM changes.

Browser

@samline/ticker/browser

ESM/CJS browser registry without installing a window global. Tree-shakable for modern bundles.

Global

/browser/global

A single IIFE for plain HTML, WordPress, Shopify, and any server-rendered template. Just one script tag.

Core

@samline/ticker/core

Types, defaults, state factories, and validation helpers for advanced integrations and custom builds.

Style

/style.css

Required layout, animation, and reduced-motion styles. One import, no CSS framework required.

03 / From zero to rolling

Three steps. No build step required.

1

Install

terminal
npm install @samline/ticker
terminal
pnpm add @samline/ticker
terminal
bun add @samline/ticker
index.html
<link rel="stylesheet" href="https://unpkg.com/@samline/ticker@2.0.4/dist/style.css">
<script src="https://unpkg.com/@samline/ticker@2.0.4/dist/browser/global.global.js"></script>
2

Add markup

Write the content as you normally would. The library enhances it, never replaces it.

index.html
<div id="news">
  <a href="/one">First story</a>
  <a href="/two">Second story</a>
  <a href="/three">Third story</a>
</div>
3

Initialize

main.ts
import { ticker } from '@samline/ticker'
import '@samline/ticker/style.css'

const news = ticker('#news', {
  duration: 20,
  pauseOnHover: true,
})
inline script
const news = window.Ticker.newTicker({
  id: 'news',
  options: { duration: 24, pauseOnHover: true },
})

05 / Good questions

Frequently asked questions.

Why not just use a CSS animation?
CSS handles the animation, while JavaScript manages clones, visibility, and changing measurements. This library provides that lifecycle. Call refresh() after updating content or loading fonts, and provide a pause control for continuous motion.
Does it work without a framework?
Yes. The browser global is a single IIFE you can drop into any plain HTML page, WordPress theme, or Shopify template. There is no build step, no peer dependency, and no window pollution beyond the Ticker namespace.
How does it handle accessibility?
Visual clones are marked aria-hidden="true" and removed from the tab order, so screen readers and keyboard users only see your original content. The library also pauses animation when the document is hidden and when the user's system reports a preference for reduced motion.
Is the native <marquee> element deprecated?
Yes — both WHATWG and the HTML living standard list <marquee> as obsolete. This library gives you the behavior people still want from a marquee, on top of a normal <div> you fully control.
Can I use it with React, Vue, or Svelte?
Yes. Pass a ref to a DOM element into the ticker() factory and call destroy() from your unmount handler. There is no framework adapter to install and no peer dependency to ship.
Does it pause when the tab is hidden?
Yes. The library listens to the document visibility API and to the IntersectionObserver for the ticker element itself, so the animation only runs when the user can actually see it. This keeps CPU and battery usage in check on long-running pages.
How big is the bundle?
Size depends on the entrypoint and your bundler’s tree shaking. The locally built v2.0.4 browser bundle is approximately 4.3 KiB gzipped, plus 0.5 KiB for the required stylesheet. There are zero runtime dependencies.
