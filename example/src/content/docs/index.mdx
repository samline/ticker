`@samline/ticker` enhances existing DOM content, measures it responsively, creates accessible visual clones, and returns a small lifecycle controller. Use the main entrypoint, declarative page manager, browser module, or global IIFE without a framework runtime.

## Why @samline/ticker?

- **Vanilla-first** — Works with native HTML, static sites, CMS templates, and server-rendered applications.
- **Multiple distribution surfaces** — Main ESM/CJS API, declarative manager, browser registry module, or `window.Ticker` IIFE.
- **Accessible defaults** — Visual clones stay out of the accessibility tree and keyboard order unless explicitly enabled.
- **Responsive lifecycle** — Resize, intersection, font, and reduced-motion changes trigger the appropriate rebuilds.
- **Zero runtime dependencies** — Ships ESM, CJS, browser bundles, CSS, and TypeScript declarations.
