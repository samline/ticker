## One native DOM runtime

Module and browser-global entrypoints share the same dependency-free measurement, cloning, observation, and cleanup behavior.

## Accessible defaults

Visual clones are hidden from assistive technology and removed from pointer and keyboard interaction unless you explicitly opt in.

## Flexible distribution

Use ESM, CommonJS, declarative HTML, or a standalone browser bundle without adopting an application framework.
