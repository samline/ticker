This page walks through installing `@samline/ticker`, loading its stylesheet, and controlling a working ticker. By the end you will understand both controller-owned and declarative lifecycles.

## Choose your setup

- **Package / ESM:** install with your package manager, import `ticker` and the stylesheet, then initialize in your application's client code.
- **HTML / CDN:** load CSS and the standalone script, then call `window.Ticker.ticker()`. A CDN delivers the files; serving them yourself uses the same API.

Both return the same controller. “Global” means the `window.Ticker` object created by the standalone script; the optional `/browser` registry module is a separate import for ID-based ownership. [See how these terms fit together](/ticker/docs/guides/html-and-browser/#loading-terms).

## Prerequisites

- **Node.js 20+** for Package / ESM tooling; HTML / CDN needs no Node.js or build step.
- A package manager — npm, pnpm, yarn or bun — for Package / ESM.
- A browser target of **ES2020**.

## First example

```html title="index.html"
<div id="news-ticker">
  <a href="/story/one">First story</a>
  <a href="/story/two">Second story</a>
</div>
```

<Tabs id="docs-initialization" label={controls.tabs.initialization} items={controls.tabs.initItems}>

<TabPanel id="module" anchor="module-example" label={controls.tabs.initItems[0].label}>

Import the stylesheet once in your application entrypoint:

```ts title="app.ts"
import { ticker } from '@samline/ticker'
import '@samline/ticker/style.css'

const news = ticker('#news-ticker', {
  duration: 24,
  direction: 'left',
  pauseOnHover: true,
})

if (!news) throw new Error('Ticker target not found')

news.update({ duration: 32 })
news.refresh()
```

</TabPanel>

<TabPanel id="global" anchor="global-example" label={controls.tabs.initItems[1].label}>

Put this JavaScript in a script after the source markup and standalone script (delivered by CDN or your own server). See the [three-file setup](/ticker/docs/guides/html-and-browser/#html--cdn-setup) to keep HTML, CSS and JavaScript separate:

```js title="main.js"
const news = window.Ticker.ticker('#news-ticker', {
  duration: 24,
  direction: 'left',
  pauseOnHover: true,
})

if (!news) throw new Error('Ticker target not found')

news.update({ duration: 32 })
news.refresh()
```

</TabPanel>

</Tabs>

What this does:

- Wraps the source content in the required ticker structure.
- Measures it and creates enough visual clones to fill the viewport.
- Keeps clones out of the accessibility tree and tab order by default.
- Rebuilds after responsive size changes.
- Returns `null` without changing the DOM if the selector is missing.

## Controller lifecycle

Destroy the controller when the view that created it is removed:

```ts
news.destroy()
```

## Declarative markup

When a server or template renders the complete ticker structure, initialize it at page level:

```html title="index.html"
<div data-ticker data-duration="24" data-direction="left" data-pause-on-hover="true">
  <div data-ticker-track>
    <div data-ticker-content>...</div>
  </div>
</div>
```

```ts title="app.ts"
import { mount, unmount } from '@samline/ticker/vanilla'
import '@samline/ticker/style.css'

mount()
window.addEventListener('pagehide', event => {
  if (!event.persisted) unmount()
})
```

<Callout title="Keep one lifecycle owner">

Use the controller API for application-owned instances and the page manager for declarative markup. Do not give both lifecycles ownership of the same element.

</Callout>
