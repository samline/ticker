`@samline/ticker` enhances existing DOM content, measures it responsively, creates accessible visual clones, and returns a small lifecycle controller. Load it through Package / ESM or HTML / CDN; choose controller, registry or declarative ownership to match your application.

## Why @samline/ticker?

- **Vanilla-first** — Works with native HTML, static sites, CMS templates, and server-rendered applications.
- **Two loading setups** — Import the package or load an HTML script tag. Both offer the same controller API and an optional ID-based registry.
- **Accessible defaults** — Visual clones stay out of the accessibility tree and keyboard order unless explicitly enabled.
- **Responsive lifecycle** — Automatic measurements reuse unchanged clones; animation pauses outside the viewport and in hidden documents.
- **Zero runtime dependencies** — Ships ESM, CJS, browser bundles, CSS, and TypeScript declarations.
